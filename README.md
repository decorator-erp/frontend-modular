# DMS (frontend-modular)

DMS is the Angular 22 modular-monolith port of the PERA production frontend, one spec at a time.

All documentation lives outside this repo, in [`decorator-erp/dms-docs`](https://github.com/decorator-erp/dms-docs) under `frontend/dms-modular-port/`: the port charter, specs and reports.
